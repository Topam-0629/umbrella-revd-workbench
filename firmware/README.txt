스마트 우산통 REV D — 자동 운전 코드 올리는 법

준비
 1. Arduino IDE 2를 설치합니다 (arduino.cc).
 2. 파일 → 기본 설정 → 「추가 보드 관리자 URL」에 아래 주소를 넣습니다.
    https://espressif.github.io/arduino-esp32/package_esp32_index.json
 3. 왼쪽 「보드 관리자」에서 esp32 (Espressif Systems)를 설치합니다. 2.0.17로 컴파일을 확인했습니다. 버전을 고를 수 있으면 2.0.17을 고르세요.
 4. 추가 라이브러리는 필요 없습니다.

올리기
 1. umbrella_revd.ino 파일 하나만 있으면 됩니다 (화면 글자도 안에 들어 있음).
    Arduino IDE가 「폴더를 만들까요?」 하면 「확인」을 누릅니다.
 2. umbrella_revd.ino를 Arduino IDE로 엽니다.
 3. 도구 → 보드 → esp32 → ESP32 Dev Module.
 4. 도구 → 포트에서 ESP32를 고릅니다 (USB 데이터 케이블).
 5. 업로드(→). 「Connecting...」에서 멈추면 ESP32의 BOOT 버튼을 누르고 있다가 글자가 올라가기 시작하면 뗍니다.
    그래도 안 되면 팬 R 신호선(GPIO2)과 VIN 선을 잠깐 빼고 올립니다.

켜면 일어나는 일
 1. 화면에 「받침이 내려갑니다」 → 두 받침을 하나씩 끝까지 내립니다 (각 최대 12초).
 2. 빈 통 거리를 잽니다. 이때 구멍에 우산을 넣어 두지 마세요.
 3. 「우산을 넣어 주세요」 화면이 나오면 준비 끝. 켠 뒤 1분 동안은 사람 감지를 무시합니다.

쓰는 법
 - 우산을 넣으면 3초 뒤 「보관 중」, 그 구멍 팬이 10분 돕니다.
 - 넣고 15초가 지난 뒤 사람이 다가오면 먼저 넣은 우산의 받침이 올라옵니다.
 - 우산을 빼면 2초 뒤 받침이 내려갑니다. 30초 안에 안 가져가면 내려가고 1분 동안 다시 안 올라옵니다.

시리얼 모니터 (115200, 줄 끝 「새 줄」)
 s   상태 보기 (거리, 기준, 팬)
 UL  L 받침 올리기 (짧은 물건처럼 센서가 못 보는 것)    UR  R
 DL  L 받침 내리기                                       DR  R
 c   빈 통 다시 재기 (받침을 내리고 우산을 다 뺀 뒤)

실물에 맞춰 바꿀 숫자 (umbrella_revd.ino 위쪽)
 MOVE_MS       끝까지 움직이는 시간. 시험 T9에서 잰 시간 + 1초. 기본 8000(8초)
 EMPTY_REF_MM  시험 T3에서 잰 빈 통 거리 {L, R}. 넣어 두면 우산이 든 채로 켜도 알아챕니다. 기본 0(켤 때 잼)
 DF_VOLUME     소리 크기 0~30

microSD
 /mp3/0001.mp3 = 사람이 다가오면 한 번 나오는 안내 음성
